# 个人向的 SwayFX 配置

确保所有 `.sh` 文件具有可执行权限 (`chmod +x`)

### 软件包

- **核心组件**: `swayfx`, `waybar`, `foot`, `mako`, `rofi`, `swaybg`, `swaynag`
- **截图与剪贴板**: `grim`, `slurp`, `wl-clipboard`, `cliphist`
- **系统工具**: `brightnessctl`, `pactl` (pulseaudio/pipewire-pulse), `bennu` (文件管理器，可以自行更换成别的)
- **输入法**: `fcitx5`, `fcitx5-chinese-addons`
- **字体**: `ttf-lxgw-wenkai`, `ttf-lxgw-wenkai-mono`

### 快捷键

`$mod` 默认为 Win 键

- `$mod + t`: 打开终端 (foot)
- `$mod + e`: 打开文件管理器 (bennu)
- `$mod + d`: 打开应用启动器 (rofi)
- `$mod + q`: 关闭当前窗口
- `$mod + Shift + t`: 打开 lite-xl（文本编辑器）
- `$mod + r`: 进入窗口缩放模式 (Resize mode)
- `$mod + Shift + c`: 重载 Sway 配置
- `$mod + Shift + e`: 退出 Sway
- `Print`: 全屏截图
- `$mod + Print`: 区域截图
- `$mod + Shift + s`: 区域截图并复制到剪贴板
- `$mod + Shift + v`: 查看剪贴板历史
